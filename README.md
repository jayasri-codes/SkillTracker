SkillTracker is a student career and skill tracking web application built with HTML, CSS and JavaScript.

[View SkillTracker](https://jayasri-codes.github.io/SkillTracker/)

## ✨ Features

- Add, edit and delete skills
- Track skill progress
- Add and manage projects
- Add and manage certifications
- Track DSA problems
- Add, edit and delete career goals
- Automatic dashboard counts
- Data saved using Local Storage
- Responsive design for mobile devices

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
- GitHub Pages

## 🎯 Purpose

SkillTracker helps students organize their technical skills, projects, certifications, DSA practice and career goals in one place.
